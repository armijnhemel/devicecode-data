Configuration File
This  page  will  allow  you  to  upload  or  download  a 
configuration file for the DAP-3320. 
Upload File:
Use  this  option  to  load  a  previously  saved 
configuration. Click Browse to find a previously 
saved configuration file. Then, click the Upload 
Settings  button  to  transfer  those  settings  to 
the access point.
Load Setting 
to Local Hard 
Drive:
Use this option to save the current access point 
configuration  settings  to  a  file  on  the  hard 
disk of the computer you are using. Click the 
Download button. You will then see a file dialog 
where you can select a location and file name 
for the settings.
