3  Building a Wireless Network 
The AP5 has the ability to operate in various modes. This chapter describes the operating modes of the AP5. 
3.1  Access Point Mode 
In Access Point Mode, AP5 behaves likes a central connection for stations or clients that support IEEE 802.11ac/b/g/n 
networks. The stations and clients must be configured to use the same SSID (Service Set Identifier) and security password 
to associate with the AP5. The AP5 supports up to eight SSIDs at the same time for secure access. 
3.2  WDS AP Mode 
The AP5 also supports WDS AP mode. This operating mode allows wireless connections to the AP5 using WDS technology. 
In this mode, configure the MAC addresses in both Access Points to enlarge the wireless area by enabling WDS Link 
settings. WDS supports four AP MAC addresses. 
3.3  WDS Bridge Mode 
In WDS Bridge Mode, the AP5 can wirelessly connect different LANs by configuring the MAC address and security settings 
of each AP5 device. Use this mode when two wired LANs located a small distance apart want to communicate with each 
other. The best solution is to use the AP5 to wirelessly connect two wired LANs, as shown in the following figure.
