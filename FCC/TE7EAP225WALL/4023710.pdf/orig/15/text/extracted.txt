1.4  Edit the SSID
By default, the dual-band EAP has two default SSIDs named TP-LINK_2.4GHz_XXXXXX 
and TP-LINK_5GHz_XXXXXX  on the 2.4GHz band and 5GHz band, and the single-band 
EAP has a default SSID named TP-LINK_2.4GHz_XXXXXX on the 2.4GHz band.
The  default  SSID  has  no  password,  so  anyone  can  access  the  network  without 
authentication. If your network is a private network, for security, we recommend that you 
change the SSID configuration immediately after login.
