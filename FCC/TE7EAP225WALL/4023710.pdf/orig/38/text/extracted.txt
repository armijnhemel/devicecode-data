External Radius Server
If you have a RADIUS server on the network to authenticate the clients, you can select 
External Radius Server. Clients need to provide the correct login information to pass the 
authentication. 
Follow the steps below to configure External Radius Server as the portal authentication 
type:
1. Build a Radius server on the network and make sure that it is reachable by the EAP.
2. Go to the Portal configuration page on the EAP. Select External Radius Server as the 
authentication type.
3. Configure the relevant parameters as the following table shows:
RADIUS Server IP
Enter the IP address of RADIUS server.
Port
Enter the port of the RADIUS server.
RADIUS 
Password
Enter the password of the RADIUS server.
