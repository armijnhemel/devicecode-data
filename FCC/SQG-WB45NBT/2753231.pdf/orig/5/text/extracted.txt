This report is prepared for FCC class II permissive change.

concerned with following:   
  Complying with New U-NII rule requirement.   
  Additional Dipole antennas. 
  Remove components to cancel BT / Wi-Fi diversity function and replace components for NAND flash.   
Therefore, all tests had been re-tested and presented in the following sections.
