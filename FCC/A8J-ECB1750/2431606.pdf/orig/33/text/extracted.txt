6  Network 
6.1  Basic 
This page allows you modify devices’ IP settings. ECB1750 supports IPv4 and IPv6. 
System Properties 
IP Address  
The IP address of this device. 
IP Subnet Mask 
The IP subnet mask of this device. 
Gateway 
The default gateway of this device. Leave it blank if you are unsure of setting. 
Primary/Secondary DNS   The primary and secondary DNS address for this device.
