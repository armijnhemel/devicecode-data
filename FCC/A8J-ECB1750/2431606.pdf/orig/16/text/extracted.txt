2.3  Computer Settings in Apple Mac OS X 
(cid:1)  Go to System Preferences (can be opened in the Applications folder or selecting it in the Apple Menu) 
(cid:1)  Select Network in the Internet & Network section 
(cid:1)  Highlight Ethernet 
(cid:1) 
(cid:1)  Enter an IP address that is different from the ECB1750 and subnet mask then press OK 
Note: Ensure that the IP address and subnet mask are on the same subnet as the device.   
In Configure IPv4, select Manually 
For example:  ECB1750 IP address: 192.168.1.1 
PC IP address: 192.168.1.2 – 192.168.1.255 
  PC subnet mask: 255.255.255.0 
(cid:1)  Click Apply when done.
