7  Wireless Setting 
7.1  Wireless Network 
This page displays the current status of the Wireless settings of the ECB1750. 
Access Point / WDS AP mode:  
2.4G/5G Wireless Network (Access Point / WDS AP mode) 
Wireless Mode 
Wireless mode supports 802.11b/g/n mixed mode in 2.4G and 802.11ac/a/n mixed mode in 5G. 
Channel HT Mode 
The default channel bandwidth is 20/40MHz and 80MHz(under 5GHz) The larger the channel, 
the better the transmission quality and speed.
