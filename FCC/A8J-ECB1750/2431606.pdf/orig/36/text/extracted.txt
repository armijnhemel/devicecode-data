Operation Mode 
Use the radio button to select an operating mode. 
Wireless Settings 2.4GHz 
Edit SSID for VLAN ID assignment, encryption setting, MAC allow, deny list and Traffic

Wireless Settings 5GHz 
Edit SSID for VLAN ID assignment, encryption setting, MAC allow, deny list and Traffic

Guest Network Settings 
Segregate temporary guest WiFi usage with individual SSID, security and bandwidth control. 
Save
