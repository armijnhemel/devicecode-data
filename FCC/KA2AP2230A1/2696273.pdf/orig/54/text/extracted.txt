Captive Portal Authentication
Captive Portal is a built-in web authentication server. When a client connects to an AP, the user’s web browser will be redirected 
to a web authentication page. In this configuration option, administrators can view and configure the Captive Portal settings. 
Web Redirection Only
After selecting Web Redirection Only as the Authentication Type, you can configure the redirection website URL that will be 
applied to each wireless client that connects to this network.
