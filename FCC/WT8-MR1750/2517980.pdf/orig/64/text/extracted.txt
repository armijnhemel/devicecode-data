8  Management  
8.1  Administration 
This page allows you to change the MR1750 username and password. By default, the username is admin and the 
password is: admin. The password can contain 0 to 12 alphanumeric characters and is case sensitive. 
Login Setting 
New Name 
Old Password 
Enter a new username for logging in to the New Name entry box. 
Enter the old password for logging in to the Old Password entry box. 
New Password 
Enter the new password for logging in to the New Password entry box. 
Confirm Password 
Re-enter the new password in the Confirm Password entry box for confirmation. 
Save/Apply / Cancel 
Click Save/Apply to apply the changes or Cancel to return previous settings.
