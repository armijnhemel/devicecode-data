6  System 
6.1  Operation Mode 
The MR1750 supports four operating modes: Access Point, WDS AP, WDS Bridge, and Repeater. 
System Properties 
Device Name 
Enter a name for the device. The name you type appears in SNMP management. This name is 
not the SSID and is not broadcast to other devices. 
Operation Mode 
Use the radio button to select an operating mode. 
Save & Apply / Cancel 
Click Save & Apply to confirm the changes or Cancel to cancel and return previous settings.
