Accessing the Web Interface
9.2 - Configured System Name Access
Note  –  “Araknis  EZ  Access”  on  page  52  must  be  enabled  for  this  access  method  to  work. 
The setting is enabled by default.
1.  See section “12.1 - System Settings” on page 32 to set the system name.
2.  Apply the settings. After configuration, the WAP web interface may be accessed using the system 
name.
3.  Open a web browser and enter the configuration address for your WAP in this format 
(Example System Name = smith100):
•  Enter into address bar: http://config.smith100.wap/
4.  Enter the login credentials. (Default: araknis/araknis)
