Advanced Features
Additional features are available under the Advanced menu. You can modify WAN settings (IPv4 & IPv6), add IPv6 firewall rules, modify LAN IP, set up 
DHCP server, enable VLAN/IPTV/MAC Clone mode, reserve the same IP address for a specific device, set up port forwarding rules to make your local 
computers accessible to other devices over the internet, enable TP-Link DDNS/SIP ALG/UPNP/fast roaming/beamforming, control Deco's LED, change 
the operation mode, set connection alerts and notifications.
