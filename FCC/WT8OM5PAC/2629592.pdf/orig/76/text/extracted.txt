Save / Restore Settings 
Using Device 
Save Settings to USB 
Save Settings 
Select to save the access point’s settings to 
your local computer or to an attached USB 
device. 
Click “Save” to save settings and a new 
window will open to specify a location to 
save the settings file. If saving settings to 
your computer or USB device, you can also 
check the “Encrypt the configuration file with 
a password” box and enter a password to 
protect the file in the field underneath, if you 
wish.   
Restore Settings from USB 
Restore Settings 
Click the browse button to find a previously 
saved settings file on your computer or 
select a settings file from your USB device.
