Web Interface Overview
10.1 - Applying Changes in the Web Interface
1.  After making changes to settings on a menu page, left-click the Save button on the menu to hold 
the new settings in the Apply Changes field.
2.  After all desired changes have been made, left-click Apply Changes to review the new settings. 
Left-click Apply to make the changes or Revert to cancel the changes.
