13.5 - Logout
Logout can be used to change the user currently logged into setup. After working in the setup screens, 
a logged in user can simply close the browser tab or click Logout. Closing the browser tab will close the 
setup screen completely, Logout will end the session for the logged in user and open the Authentication 
Required (Log In) window. 
Figure 60. Logout Alert
Path – Maintenance, Logout
Configuration Instructions –   
1.  From any screen, click Logout in the system menu. The Logout ALERT will appear on screen.
2.  Click Cancel to return to the setup screen; click Confirm to log the current user out.
