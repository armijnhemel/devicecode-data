12.2 - LAN Settings
The  LAN  Settings  screen  allows  configuration  of  the  access  point  LAN  connection  to  the  network 
router. In default mode, the IP Settings screen will show the DHCP IP address and default subnet mask. 
A static IP address, subnet mask, default gateway and DNS settings can be configured by disabling 
DHCP. LAN speed can also be configured in the Interface Settings menu.
