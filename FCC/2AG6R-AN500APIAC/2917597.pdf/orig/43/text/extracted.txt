12.3.4 - Wireless Security Menu
The Wireless Security menu opens during the setup of an existing or new wireless network.
12.3.4.1 - WPA-PSK Mixed and WPA2-PSK Modes
Figure 37.  Wireless Security – WPA-PSK and WPA2-PSK Modes
Path – Settings, Wireless, Wireless Networks, Security Mode
Parameters – 
•  Name (SSID) – The name of the network being configured.
•  Security Mode – Select a mode from the drop-down. Use the same mode as the network router 
and other APs on the network. Selecting a non-PSK mode will cause the menu options to change.
•  Encryption – WPA2-PSK: AES; WPA2-PSK Mixed: Both (TKIP+AES).
•  Passphrase – Enter the appropriate passphrase for the wireless network being configured. If using 
the ASCII format, the password must be 8-63 characters in length. If using HEX, the password 
must be 64 HEX characters in length.
Default: Blank
•  Group Key Update Interval – Enter a value to specify how often in seconds the Group key 
changes. RANGE: 30-3600 seconds.
Default: 3600 (60 minutes)
•  Save – Click to save changes to the Wireless Security Settings for this network. The window will 
close.
•  Cancel – Click to cancel changes to the Wireless Security Settings for this network. The window 
will close.
