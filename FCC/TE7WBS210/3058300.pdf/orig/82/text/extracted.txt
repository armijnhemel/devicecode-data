Chapter 8 System Tab 
Current User Name 
Displays the current user name. 
Current Password 
Enter  the  current  password  for  the  user  account.  Check  the  Show  box  to 
display what you've entered. 
New User Name 
Enter the new user name for the user account. 
New Password 
Enter the new password for the user account. Check the Show box to display 
what you've entered. 
Confirm New Password 
Re-enter the new password for the user account. 
NOTE: 
The password is a string from 1 to15 alphanumeric characters or symbols.  
Time Setting 
Time Zone 
Select your local time zone from the drop-down list.
